# Cuecraft

Cuecraft is a local-first rehearsal console for stage managers and live event teams. It turns a dense run of show into a calm, accessible workspace for checking cue readiness, spotting timing collisions, and keeping every department aligned.

## Requirements

- Node.js 20
- npm

## Development

```sh
npm ci
npm run dev
```

## Validation

```sh
npm test
npm run lint
npm run typecheck
npm run build
```

The application uses deterministic sample data and browser storage only. It requires no credentials or external services.
